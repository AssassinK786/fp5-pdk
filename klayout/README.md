# FP5 KLayout files

The installable decks are in `../fp5A/libs.tech/klayout/`; the files here are
the legacy source/reference copies.

- `layers.txt`: GDS layer numbers (MOSIS SCMOS numbering, used by the OSU
  cells and the qflow Magic tech).
- `fp5.drc`: legacy DRC deck (public MOSIS SCMOS SUBM rules, lambda 0.30 um).
  The installable copy is `fp5A/libs.tech/klayout/fp5A.drc`.
- `fp5.lvs`: MOS LVS deck. The installable copy is
  `fp5A/libs.tech/klayout/fp5A.lvs`. It extracts fp5n/fp5p with W/L and
  matches nfet/pfet, nmos/pmos model classes. Passives/diodes/PNP are not yet
  extracted.
- `cell_checks/`: per-cell DRC/LVS logs generated by `check_cells.sh`.
- `pcells/fp5_pcells.py`: KLayout PCells for nmos, pmos, rpoly, cpoly, gring.

Run the legacy check with:

```bash
./klayout/check_cells.sh
```

The script now writes absolute report paths and fails if a report is missing;
this fixes the old relative-path false-pass.
