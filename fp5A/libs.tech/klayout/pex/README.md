# FP5A OpenRCX rules

`fp5A.rcx` is a first-order 3-metal OpenRCX ruleset **calibrated to the
MOSIS T89Y interconnect data** in `../../../tech/wire_rc.txt`. It is
generated by `validation/pex/gen_rcx.py` — edit that script, not the deck.

| layer | Rsh (ohm/sq) | C at min width (fF/um) |
|---|---|---|
| metal1 | 0.09 | 0.129 |
| metal2 | 0.09 | 0.077 |
| metal3 | 0.05 | 0.064 |

The deck's DIST rows are `sep_um  coupling_fF/um  fringe_fF/um  res_ohm/um`
(see OpenROAD `extDistRC::readRC`). Isolated-wire ground capacitance and
sheet resistance match `wire_rc.txt` exactly; lateral coupling uses a
`w/(w+sep)` analytic falloff, so coupling values are estimates within the
right asymptotes, not field-solved.

See `validation/pex/` for the generator and self-check output. A
field-solver-calibrated deck (e.g. FasterCap) remains future work.
